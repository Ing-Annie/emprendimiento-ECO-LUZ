# ECOLUZ - Lámparas de tutuma

Sitio web de ventas de ECOLUZ. Es una página estática: HTML, CSS y JavaScript, sin instalación.

## Archivos
- `index.html`: la página completa.
- `*.jpg`: logo, fotos de productos, plantillas y procesos de elaboración. Deben quedar en la misma carpeta que `index.html`.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube todos los archivos de esta carpeta a la raíz del repositorio.
3. Entra a Settings > Pages, elige la rama `main` y la carpeta `/ (root)`, y guarda.
4. En unos minutos la página queda disponible en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`.

## Para editar
- Productos y precios: en `index.html`, busca la lista `PRODUCTS` dentro de la etiqueta `<script>` (nombre, descripción, precio en Bs, foto).
- Enlaces de redes y WhatsApp: busca el objeto `LINKS`.

## Notas
- Los pedidos se envían por WhatsApp. La página no cobra ni confirma pagos.
- El carrito se guarda solo en el navegador de cada visitante.
